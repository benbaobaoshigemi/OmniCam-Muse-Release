# OmniCam Muse

Find X9 Ultra（PMA110）的相机增强：理光 GR、POP 复古、X10 滤镜与调色盘、大师模式（大师色彩、滤镜补全、颗粒与对比度）、自然模式、哈苏超清、移轴、普通模式 25MP、物理柔光、XPAN 显影实况等。

本仓库只发布安装包，不含源码。下载见 [Releases](../../releases)。

## 环境

- 机型 Find X9 Ultra（PMA110），相机版本 7.006.119
- 已 root（KernelSU），已装 LSPosed

## 安装

1. 从 Releases 下载 `OmniCam-Muse-Release-<版本>-KSU.zip`。
2. 在 KernelSU 管理器里刷入该模块（ID `ricoh_pop_x9u`），重启。模块包内自带设置 App（包名 `local.jiege.camera`），刷入时一并安装。
3. 在 LSPosed 里启用 OmniCam Muse，作用域勾选系统框架、相机、相册。
4. 强制停止相机后重新打开。

设置在桌面的 OmniCam Muse App 里，或从 LSPosed 打开。

| 实验性：物理柔光（弱 HDF、中 1/4 黑柔、强白柔） | 哈苏超清 200MP 解除人脸识别门禁 |
| | 实验性：和光物理胶片 |

授权是离线的，绑定一台设备，永久有效：

1. 打开 OmniCam Muse App，在主页授权卡片里复制申请码（`MUSE1-` 开头）。
2. 把申请码发给作者，换回授权码（`MUSE2.` 开头）。
3. 在授权卡片里粘贴授权码，激活。
4. 强制停止相机后重新打开。

授权码只对申请它的那台设备和 Muse 3.x 有效。在授权卡片里可以取消授权。

## 排查

App 主页的“注入状态”逐项检查 LSPosed、KSU 模块、相机注入、符号匹配和功能加载，全部正常时顶部卡片为绿色。

- 相机还在用旧版本时点“重启相机”（需要在 KernelSU 里给 App 授予 Root；没有 Root 时会打开相机的应用信息页，点“强行停止”后重开相机）。
- 遇到问题点“导出日志”，把生成的 zip 发给作者。日志不含授权码；给 App 授予 Root 时会一并带上 LSPosed 日志和系统日志。

## 回退

在 KernelSU 管理器里停用模块并重启，所有挂载即还原。
